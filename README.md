# PIP-CO-Startup-Systems
PIP-CO Startup Systems adds customizable startup animations and audio to the Wand Company Pip-Boy 3000, with modular install support so users can choose only the startup packs they want. Includes Default, Special, Factions and NPC startup sequences while keeping the core lightweight and memory-conscious.

Compatiable with PIP-CO-Idle-Framworks.
